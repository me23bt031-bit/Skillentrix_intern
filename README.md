# AutoCAD 3D Modeling Internship Projects

## Overview
3D solid modeling projects created in **AutoCAD Student Edition**, based on engineering drawings from the Solid Edge practice workbook *(spse01550 — Practicing your skills with projects, Lesson 2)*.

## How to Open the Models
1. Open **AutoCAD** (2018 or later / Student Edition)
2. `File → Open` → Select the `.dwg` file
3. Type `3DORBIT` to rotate and inspect the 3D model
4. Type `HIDE` for hidden-line view, `SHADE` for shaded view

## How to Run the Scripts
1. Open AutoCAD
2. Type `SCRIPT` at the command prompt
3. Browse to the `.scr` file → Open
4. Follow any manual prompts for Boolean selections
